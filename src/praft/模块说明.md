## 使用示例

### 初始化集群
```bash
redis-cli RAFT.CLUSTER INIT 127.0.0.1:12221,127.0.0.1:12222,127.0.0.1:12223 db0
```

### 获取集群状态
```bash
redis-cli RAFT.CLUSTER INFO db0
```

### 管理节点
```bash
redis-cli RAFT.NODE ADD 127.0.0.1:12224 db0
redis-cli RAFT.NODE REMOVE 127.0.0.1:12224 db0
```

### 查询配置
```bash
redis-cli RAFT.CONFIG GET election-timeout-ms
redis-cli RAFT.CONFIG GET group-id
```

## 配置要求

在 `conf/pika.conf` 中：
```ini
raft-enabled : yes
raft-group-id : pika_raft_group
raft-peers : 127.0.0.1:12221,127.0.0.1:12222,127.0.0.1:12223
raft-election-timeout-ms : 1000
raft-snapshot-interval-s : 3600
```

## API 接口

### RaftManager 公共方法
- `Init()` - 初始化管理器
- `Start()` - 启动 Raft 管理器
- `Shutdown()` - 关闭管理器
- `InitCluster()` - 初始化新集群
- `JoinCluster()` - 加入现有集群
- `AddNode()` - 添加节点到集群
- `RemoveNode()` - 从集群移除节点
- `GetClusterInfo()` - 获取集群状态
- `ApplyCommand()` - 通过 Raft 应用命令

### PikaRaftNode 公共方法
- `Init()` - 初始化节点
- `Start()` - 启动节点
- `Shutdown()` - 关闭节点
- `IsLeader()` - 检查是否为 leader
- `GetLeaderId()` - 获取当前 leader
- `AddPeer()` - 添加 peer
- `RemovePeer()` - 移除 peer
- `Apply()` - 应用日志条目
- `GetStatus()` - 获取节点状态

### PikaStateMachine 回调
- `on_apply()` - 应用已提交的日志
- `on_snapshot_save()` - 保存快照
- `on_snapshot_load()` - 加载快照
- `on_leader_start()` - Leader 当选
- `on_leader_stop()` - 失去 leadership
- `on_error()` - 发生错误
- `on_configuration_committed()` - 配置变更
- `on_start_following()` - 开始跟随
- `on_stop_following()` - 停止跟随
